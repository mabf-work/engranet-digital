# Engranet Digital

Sitio web y panel administrativo de Engranet Digital.

- Sitio público: `/`
- Panel administrativo: `/admin` (usuarios de Supabase Auth registrados en la tabla `admins`)
- Base de datos: ejecutar `supabase/schema.sql` en el SQL Editor de Supabase

Stack: Vite + React + TypeScript + Supabase.
